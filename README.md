# Basic Informational Site
Proyecto del curso [The Odin Proyect](https://www.theodinproyect.com/).

## Descripcion
Servidor HTTP con Node.js puro (sin frameworks) que sirve 4 paginas HTML estaticas.

## Rutas
- "/" => Home
- "/about" => About
- "/contact-me" => Contact
- Cualquier otra => 404

# Tecnologias
- Node.js
- Modulos "Http", "fs", "path"

''' bash
node --watch index.js
